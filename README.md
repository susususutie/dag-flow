# dag-flow

`dag-flow` 是一个基于 React 的交互式 DAG 画布组件库。它使用 nodes 描述节点，通过嵌套 flow 表达串行与并行拓扑，并自动完成节点布局与连线渲染；同时提供自定义节点、受控与非受控状态、节点选择与删除、画布平移缩放、视图适配、缩略图及工具栏等能力，适用于拓扑结构由流程顺序确定的编排、展示和编辑场景。

A starter for creating a Vite Plus project.

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp pack
```
